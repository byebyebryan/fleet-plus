Local cached read

A separately running Observer service publishes host-local facts. Your utility reads that cache; reading does not start a daemon or renew native evidence.

Read all three cases

Local clients read an explicitly hosted cache. Fleet clients add optional Mesh delivery through configured routes. Missing, incomplete or expired evidence remains uncertain; it cannot establish idle work, removal or an empty working set.

These controls explain the architecture. They do not contact a runtime or change a configuration.
